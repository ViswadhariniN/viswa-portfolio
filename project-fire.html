PROJECT 01

Smart GSM-Free Fire Alert and Monitoring System

An IoT-based fire monitoring system designed to monitor environmental conditions and provide alerts through internet connectivity without using a GSM module.

Project Gallery

Project Overview

The Smart GSM-Free Fire Alert and Monitoring System is designed to improve fire safety in warehouses. It monitors environmental parameters such as temperature, humidity, oxygen level and carbon dioxide level. The system uses internet connectivity to provide alerts without depending on a GSM module.

Project Objective

The main objective is to develop a smart fire monitoring system that can continuously monitor environmental conditions, identify possible fire-related risks and notify the responsible people through internet-based communication.

Working Principle

01. Monitoring

Sensors continuously monitor environmental parameters inside the warehouse.

02. Detection

The system checks the monitored values to identify abnormal environmental conditions.

03. Alert Generation

When abnormal conditions are detected, the system generates an alert.

04. Internet Notification

Alerts can be communicated through internet connectivity without using a GSM module.
