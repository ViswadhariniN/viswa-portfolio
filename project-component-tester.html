PROJECT 02

Portable Component Tester

A compact microcontroller-based electronic testing device designed to check the functionality of basic electronic components and display their measured values.

Project Gallery

Project Overview

The Portable Component Tester is designed to test commonly used electronic components such as resistors, capacitors, diodes and transistors. The device uses a microcontroller to measure electrical parameters, process the readings and display the results on an LCD display. A ZIF socket is used to make component insertion and removal easier.

Project Objective

The main objective is to develop a compact and portable testing device that helps users quickly identify the functionality and basic electrical characteristics of electronic components. It aims to make component testing easier and more convenient without requiring separate testing instruments for every component.

Working Principle

01. Component Insertion

The electronic component is inserted into the ZIF socket provided in the testing device.

02. Signal Application

Suitable DC, AC or pulse signals are applied to the component for testing.

03. Parameter Measurement

Electrical measurements such as voltage, current and time-related response are obtained using the measurement and ADC circuitry.

04. Result Display

The microcontroller processes the measurements and displays the calculated component values on the LCD screen.
